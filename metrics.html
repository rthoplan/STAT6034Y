1. The Validation & Test Rule

Validation is the practice exam. The Test set is the final exam. You use validation error to choose your model settings. You use the test set exactly once to estimate final performance.

Select the model with the lowest validation error.
Stop! You have seen the test error. If you go back and pick a different model because you didn't like the test score, the test is no longer honest! It has leaked into your training process.

The Accuracy Trap

If a dataset is highly imbalanced, Accuracy is a terrible metric.

Scenario: 90% of customers naturally stay. You build a "dumb" baseline model that simply predicts "Everyone will stay".

Baseline Accuracy 90%
Churners Found (Sensitivity) 0%

The model looks great on paper (90%), but is completely useless for the business problem. This is why a simple baseline is required for comparison.
