Evaluation Metrics Formula Reference

1. Accuracy Overall correctness
Accuracy = (TP + TN) / (TP + TN + FP + FN)

Measures the proportion of total predictions (both positive and negative) that were correct.

2. Sensitivity (Recall / TPR) True Positive Rate
Sensitivity = TP / (TP + FN)

Measures how well the model detects actual positive cases out of all real positives.

3. Specificity (TNR) True Negative Rate
Specificity = TN / (TN + FP)

Measures how well the model identifies actual negative cases out of all real negatives.

4. Precision (PPV) Positive Predictive Value
Precision = TP / (TP + FP)

Measures how many of the model's positive predictions were actually correct.
