Core Question: Will it work on new data?

A model is useful only if its performance estimate is credible for future cases. To guarantee this, we must enforce a Future-Like Test. We pretend that part of our dataset is future data, and the model is strictly not allowed to learn from it.

Training Set

Used to fit the model. The algorithm learns patterns, relationships, and rules exclusively from this data.

Validation Set

The "Practice Exam". Used to choose model settings, tune parameters, and select the best candidate model.

Test Set

The "Final Exam". Used once to estimate final performance. If test results change your model, it's no longer a true test!

The Golden Rule of the Test Set

Important: A record used for training must not also appear in the test set.

Furthermore, you must use the test set only once. If the test result makes you go back and change your model, it is no longer a true test; it has leaked into your training process!
